# Install THUMDER

THUMDER is the same everywhere: the simulator, the examples and the exercises do not change. Choose the version that suits you.

| Where | How | Works offline |
| :-- | :-- | :-- |
| Browser | Open <https://thumder.netlify.app> | No: the page loads from the internet |
| Windows, Linux and macOS | The desktop application, from the [GitHub releases](https://github.com/nonodev96/THUMDER/releases) | Yes |
| Android | The APK, from the same releases | Yes |
| iPhone and iPad | In Safari, added to the home screen | No, as in the browser |

## In the browser

Open <https://thumder.netlify.app> in an up to date browser (Chrome, Edge, Firefox or Safari). No account is needed: your files are kept in that browser.

On a phone, the menu of the browser offers **Add to home screen**: THUMDER then opens full screen, like an application.

## On the desktop

Download the file for your system from the latest release on [GitHub](https://github.com/nonodev96/THUMDER/releases):

- **Windows**: the installer (`.exe`) or the portable version, which is not installed.
- **Linux**: the `.AppImage`. Make it executable (in the properties of the file, or with `chmod +x THUMDER-*.AppImage`) and open it.
- **macOS**: the `.dmg`. Drag THUMDER to **Applications**.

The applications are not signed (the certificates of Windows and macOS cost money), so the first time the system warns you:

- On Windows, SmartScreen: **More info → Run anyway**.
- On macOS, Gatekeeper: open THUMDER with a right click → **Open**, or allow it in **System Settings → Privacy & Security**.

If you want to check that a file is the one GitHub built, the [README](../../README.en.md) explains how to verify where it comes from.

The application does not update by itself: to get the new version, download it again. Your files and your settings are kept.

## On Android

1. Download the `.apk` of the latest release on [GitHub](https://github.com/nonodev96/THUMDER/releases) from the phone.
2. Open it. Android asks for permission to install applications from the browser: allow it.
3. To update, download and install the APK of the new version over it.

## On iPhone and iPad

There is no application in the App Store yet. Use THUMDER in Safari and, with **Share → Add to Home Screen**, you get its icon like an application's.

## And my files?

Each browser and each device keeps its own files. To have the same ones everywhere, sign in with an account: [Account and privacy](cuenta.en.md). Without an account, you can take them from one place to another by downloading and importing them in the [file manager](ficheros-y-editor.en.md).
