# Instalar THUMDER

THUMDER es el mismo en todas partes: el simulador, los ejemplos y los ejercicios no cambian. Elige la versión que te venga mejor.

| Dónde | Cómo | Funciona sin conexión |
| :-- | :-- | :-- |
| Navegador | Abre <https://thumder.netlify.app> | No: la página se carga de internet |
| Windows, Linux y macOS | La aplicación de escritorio, de las [versiones de GitHub](https://github.com/nonodev96/THUMDER/releases) | Sí |
| Android | El APK, de las mismas versiones | Sí |
| iPhone y iPad | En Safari, añadida a la pantalla de inicio | No, como en el navegador |

## En el navegador

Abre <https://thumder.netlify.app> en un navegador actual (Chrome, Edge, Firefox o Safari). No hace falta cuenta: tus ficheros se guardan en ese navegador.

En el móvil, el menú del navegador ofrece **Añadir a la pantalla de inicio**: THUMDER se abre entonces a pantalla completa, como una aplicación.

## En el escritorio

Descarga el fichero de tu sistema de la última versión en [GitHub](https://github.com/nonodev96/THUMDER/releases):

- **Windows**: el instalador (`.exe`) o la versión portable, que no se instala.
- **Linux**: el `.AppImage`. Dale permiso de ejecución (en las propiedades del fichero, o con `chmod +x THUMDER-*.AppImage`) y ábrelo.
- **macOS**: el `.dmg`. Arrastra THUMDER a **Aplicaciones**.

Las aplicaciones no están firmadas (los certificados de Windows y macOS son de pago), así que la primera vez el sistema avisa:

- En Windows, SmartScreen: **Más información → Ejecutar de todas formas**.
- En macOS, Gatekeeper: abre THUMDER con clic derecho → **Abrir**, o permítelo en **Ajustes del Sistema → Privacidad y seguridad**.

Si quieres comprobar que un fichero es el que compiló GitHub, el [README](../../README.md) explica cómo verificar su procedencia.

La aplicación no se actualiza sola: para tener la versión nueva, descárgala otra vez. Tus ficheros y tu configuración se conservan.

## En Android

1. Descarga el `.apk` de la última versión en [GitHub](https://github.com/nonodev96/THUMDER/releases) desde el móvil.
2. Ábrelo. Android pide permiso para instalar aplicaciones desde el navegador: concédelo.
3. Para actualizar, descarga e instala el APK de la versión nueva encima.

## En iPhone y iPad

Todavía no hay aplicación en la App Store. Usa THUMDER en Safari y, con **Compartir → Añadir a la pantalla de inicio**, tendrás su icono como el de una aplicación.

## ¿Y mis ficheros?

Cada navegador y cada dispositivo guarda sus propios ficheros. Para tener los mismos en todos, inicia sesión con una cuenta: [Cuenta y privacidad](cuenta.md). Sin cuenta, puedes llevarlos de un sitio a otro descargándolos e importándolos desde el [gestor de ficheros](ficheros-y-editor.md).
